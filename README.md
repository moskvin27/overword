# Overword

Читалка английских книг в PDF с подстрочным переводом. Работает прямо в браузере (Chrome или Edge на компе), без сервера.

- Клик по слову — перевод встаёт над ним, слово попадает в словарь и звучит.
- Все формы слова на странице подсвечиваются его цветом (ran → run, ships → ship).
- Клик по подсвеченному — карточка: значения, транскрипция, озвучка, перевод всего предложения.
- В памяти только текущая страница и две соседние — листать можно хоть 1000 страниц.
- Синхра словаря и места в книге между компами через приватный GitHub Gist.

Сайт: https://moskvin27.github.io/overword/

## Устройство

- `docs/` — сам сайт (выкладывается на GitHub Pages при каждом пуше в `main`).
- `docs/data/dict.json` — словарь, собранный скриптом `tools/build_dict.py` из англо-русского словаря В. К. Мюллера (7-е изд., GPL).
- `docs/vendor/pdfjs` — pdf.js от Mozilla (Apache 2.0).
- Перевод предложений — встроенный переводчик Chrome (Translator API), работает на компе без интернета.

Книги никуда не загружаются: файл хранится только в браузере на твоём компе.
